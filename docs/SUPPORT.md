# Spelunkr TV Support

Use the Siri Remote to browse the Live guide. Select a channel or choose **Watch live** to tune in. Use **Favorite** to save a channel, and **Back** to return to the guide.

If a channel fails to play, retry or try another channel. The app needs internet access and relies on the published Spelunkr schedule and Internet Archive recordings. Set the Apple TV's date and time automatically to keep playback aligned with the schedule.

For help, [open a GitHub issue](https://github.com/fragmede/spelunkr-tv/issues/new). Include your Apple TV model, tvOS version, channel, and what happened. Issues are public. Keep personal information out of them.
